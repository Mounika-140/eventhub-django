# Code of Conduct

## Our Commitment

We are committed to providing a welcoming and inspiring community for all. We expect all participants in this project to treat each other with respect and dignity.

## Our Standards

### Positive Behavior
- Use welcoming and inclusive language
- Be respectful of differing opinions and experiences
- Give and receive constructive feedback gracefully
- Focus on what is best for the community
- Show empathy towards other community members
- Help create a safe environment

### Unacceptable Behavior
- Harassment, discrimination, or intimidation
- Offensive language or jokes
- Trolling, insulting, or derogatory comments
- Public or private attacks
- Publishing private information without permission
- Spam or unwanted promotion
- Any form of abuse

## Enforcement

### Reporting Issues
If you witness or experience unacceptable behavior:
1. Report to project maintainers
2. Provide specific details and examples
3. Be prepared to assist in investigation

### Consequences
Violations may result in:
- Warning
- Temporary or permanent ban
- Removal from project

## Scope

This Code of Conduct applies in ALL project spaces including:
- GitHub issues and pull requests
- Project discussions
- Community forums
- Project events
- Social media related to the project
