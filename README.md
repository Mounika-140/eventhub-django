# EventHub – Event Organization Management System

EventHub is a full-stack web application built using **Python, Django, HTML, CSS, and JavaScript** that allows organizers to create and manage events while students can explore, view, and participate in upcoming events.

The platform provides separate dashboards for **event organizers and users**, making it easy to manage event details, track events, and view important information in a structured way.

## Features

* User registration and login system
* Organizer registration and dashboard
* Create and manage events
* View event details and posters
* Student dashboard to explore events
* Responsive UI using HTML, CSS, and JavaScript
* Backend logic implemented using Django
* SQLite database for storing user and event data

## Tech Stack

* **Backend:** Python, Django
* **Frontend:** HTML, CSS, JavaScript
* **Database:** SQLite
* **Version Control:** Git & GitHub

## Project Structure

The project follows a clean Django structure with separate folders for applications, templates, static files, and backend configuration.

## Installation

1. Clone the repository

git clone https://github.com/Mounika-140/eventhub-django.git

2. Navigate to the project directory

cd eventhub-django/DemoProject

3. Install dependencies

pip install -r requirements.txt

4. Run the development server

python manage.py runserver

5. Open the application in your browser

http://127.0.0.1:8000/
